
【广告行业翻译规则 — 本平台 100% 是广告、营销传播与媒体行业内容，严格遵守】

1. 歧义默认值：以下词在中文有非广告歧义，**一律按广告行业含义翻译**：
   - Campaign = 广告战役 / 营销战役（不译"运动"/"竞选"，除非原文确实在讲政治竞选）
   - Account = 客户业务（代理商语境，如 "won the account" 译"赢得该客户业务"，不译"账户"）
   - Pitch = 比稿（不译"推销"/"音高"）
   - Brief = 创意简报 / 需求简报
   - Creative = 创意 / 创意作品（作名词时）
   - Agency = 代理商 / 广告公司（不译"机构"/"中介"）
   - Holding company / Holdco = 控股集团（广告控股集团）
   - Media = 媒介 / 媒体（"media agency" 译媒介代理商，"media buying" 译媒介采购）
   - Placement = 广告位 / 投放位置
   - Inventory = 广告库存
   - Impression = 曝光（不译"印象"）
   - Reach / Frequency = 触达 / 频次
   - Attribution = 归因
   - Measurement = 效果衡量
   - Brand safety = 品牌安全
   - Retail media = 零售媒体
   - Influencer / Creator = 达人、网红 / 创作者
   - Earned media = 自来水（赢得媒体）；Owned media = 自有媒体；Paid media = 付费媒体
   - Upfront / Upfronts = 预售会（电视与流媒体广告的年度预售）
   - Shortlist = 入围名单；Grand Prix = 全场大奖（Grand Prix 可保留英文）；Gold / Silver / Bronze Lion = 金狮 / 银狮 / 铜狮

2. 以下专有名词**一律保留英文原文**或使用通行中文名，不另加解释：
   - 控股集团与代理商：WPP / Publicis（阳狮）/ Omnicom（宏盟）/ IPG / Dentsu（电通）/ Havas（哈瓦斯）/ Ogilvy（奥美）/ BBDO / TBWA / DDB / McCann（麦肯）/ Leo Burnett（李奥贝纳）/ VML / Wieden+Kennedy / Droga5 / Mother / GroupM / OMD / Mindshare / Starcom / Carat
     **规则**：已有通行中文名的用中文名（首次出现可双标"阳狮（Publicis）"），其余保留英文，不自造译名
   - 平台与广告产品：Google Ads / YouTube / Meta Advantage+ / Amazon Ads / TikTok / 巨量引擎 / 阿里妈妈 / 腾讯广告 / The Trade Desk / Netflix Ads
   - 奖项与行业活动：Cannes Lions（戛纳国际创意节）/ One Show / D&AD / Clio / Effie（艾菲奖）/ ADC / Spikes Asia / 长城奖 / 金投赏
   - 技术缩写（举例 + 通用规则）：CTV / OTT / DSP / SSP / DMP / CDP / RTB / PMP / CPM / CPC / CPA / ROAS / ROI / GRP / OOH / DOOH / SEO / SEM / UGC / PGC / KOL / KOC / MCN
     **规则**：任何 2-5 字母的全大写缩写，默认按广告营销含义保留英文
   - 通用技术：AI / API / SDK / SaaS / CDN / SSO / Cookie / IDFA

3. 品牌名：中国市场有官方中文名的品牌用中文名（耐克、可口可乐、麦当劳、苹果），没有通行中文名的保留英文；战役名和作品名保留原文，可在首次出现时意译一次（如 "Real Beauty"（真美））。

4. 代码 / 命令 / URL / 数字单位 **一字不改**保留：
   - URL 原样
   - 数字+单位：$2.5B / 15% YoY / 3.2x ROAS / 10M impressions / 99.9%
   - 金额、比例、区间必须保留原文的阿拉伯数字和单位；不要把 $10B-$100B 改写成“数百亿至数千亿美元”等中文数量词
